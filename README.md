# 📂 Telegram File Manager Bot (Cloud Storage)

**Личный Файловый Менеджер в Telegram.**
Это продвинутое облачное хранилище с поддержкой **папок**, вложенности и удобной навигацией. Бот позволяет сохранять файлы, сортировать их по папкам, перемещать между ними и удалять.

Интерфейс построен на **текстовых командах**, что позволяет быстро работать с большими списками файлов без ограничений инлайн-кнопок.

## 🚀 Возможности (v7.1)

*   **📂 Система папок:** Создание папок и подпапок любой глубины (`/mkdir`).
*   **💾 Всеядность:** Сохраняет Фото, Видео, Аудио, Голосовые, Документы и **GIF-анимации**.
*   **📑 Пагинация:** Разбиение списков на страницы (по 15 объектов) с навигацией.
*   **📦 Мульти-перенос:** Выделение нескольких файлов галочками и перемещение их в другую папку (`/paste_all`).
*   **🧠 Умные названия:** Авто-определение Исполнителя/Трека для музыки и имен файлов.
*   **🗑 Полное удаление:** При удалении папки удаляется всё её содержимое.
*   **🛡 Безопасность:** Токен скрыт в `.env`.

## ⚙️ Установка и Запуск

### 1. Установка зависимостей
Откройте терминал в папке проекта:
```bash
npm install
```
*(Или вручную: `npm install mysql2 node-telegram-bot-api dotenv`)*

### 2. Настройка Базы Данных (MySQL)
Откройте PHPMyAdmin (или консоль MySQL).
1. Создайте базу данных `ChatBotTests`.
2. Выполните следующий SQL-запрос для создания структуры:

```sql
CREATE DATABASE IF NOT EXISTS ChatBotTests;
USE ChatBotTests;

-- Таблица пользователей (хранит текущую папку юзера)
CREATE TABLE IF NOT EXISTS Users (
    id BIGINT PRIMARY KEY,
    current_folder_id INT DEFAULT 0
);

-- Таблица папок
CREATE TABLE IF NOT EXISTS Folders (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT,
    name VARCHAR(255),
    parent_id INT DEFAULT 0
);

-- Таблица файлов
CREATE TABLE IF NOT EXISTS Storage (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT,
    type VARCHAR(50),
    file_id VARCHAR(500),
    caption TEXT,
    folder_id INT DEFAULT 0
);
```

### 3. Настройка окружения
Создайте в корне файл `.env` и вставьте токен:
```bash
TELEGRAM_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
```

### 4. Запуск бота
```bash
node index.js
# или
nodemon index.js
```

## 💡 Инструкция пользователя

### Начало работы
*   `/start` — Приветствие и регистрация.
*   `/help` — Полный список команд.
*   `/list` — Обновить текущий список.

### Управление файлами и папками
1.  **Сохранение:** Просто отправьте боту файл, фото или видео.
2.  **Папки:**
    *   `/mkdir Работа` — Создать папку "Работа".
    *   `/open_ID` — Открыть папку (синяя ссылка в списке).
    *   `/up` — Вернуться назад (на уровень выше).
    *   `/rmdir_ID` — Удалить папку со всем содержимым.
3.  **Файлы:**
    *   `/get_ID` — Скачать файл.
    *   `/del_ID` — Удалить файл.

### ✂️ Перемещение файлов (Мульти-выбор)
1.  Нажмите на команду `⬜ /sel_ID` в конце строки с файлом (она превратится в `✅`).
2.  Выберите так несколько файлов.
3.  Перейдите в папку, куда хотите их переместить.
4.  Нажмите `/paste_all` (команда появится вверху списка).
5.  Чтобы отменить выбор: `/clear_sel`.
